Architecture

Full-Duplex Real-Time Pipeline

AST grounding, sub-second interruption, and cloud AI

⚡ Real-Time Voice Gateway

16kHz PCM audio pushed over WebSockets to AssemblyAI Streaming STT. Emits real-time visual events and coordinates sub-50ms barge-in interruption.

🔍 Semantic AST Diff Grounder

Parses unified git diffs into structured hunks. Resolves fuzzy spoken questions to specific functions, classes, and line numbers before querying LeMUR.

Speaker Note: "Our architecture pairs a Node.js full-duplex WebSocket gateway with our AST DiffIndexer. When developer speech comes in, the DiffIndexer resolves the inquiry to target lines and sends the contextual diff into LeMUR."
