# Scripting & Post Templates

Reusable, plug-and-play templates for long-form video, short-form clips, and social posts.

---

## Template 1: YouTube Long-Form Two-Column Script

Use the classic AV (Audio-Visual) table format. This forces you to plan what the viewer sees while hearing your voice.

| Timecode | Visual / Screen Action (What they see) | Audio / Script (What you say) |
| :--- | :--- | :--- |
| **0:00 - 0:15** | [Close-up on host. Fast snap zoom on key phrase. On-screen graphic of the problem.] | "Most developers spend hours debugging X, only to realize they made this exact 1-line mistake." |
| **0:15 - 0:35** | [Screen recording: Show the failure state or live error message in red.] | "Here is what happens when you run it normally. It crashes. Today, I'm showing you the 3 rules that fix this permanently." |
| **0:35 - 1:30** | [B-roll: Architecture diagram showing why standard solutions fail.] | "Before we write the code, look at why the standard documentation leads you astray..." |
| **1:30 - 4:00** | [Screen share: IDE with high contrast theme, font size 18pt+. Live typing, no typos.] | "Step 1: Replace this naive loop. Notice what happens to memory consumption..." |
| **4:00 - 4:15** | [Pattern interrupt: Cut back to facecam, SFX whoosh.] | "Now, this works, but there's a catch that almost nobody talks about." |
| **4:15 - 7:30** | [Terminal benchmark comparison side-by-side.] | "Step 2: Here is the benchmark before and after. Notice the 4x difference..." |
| **7:30 - 9:30** | [Final working demo / live project test.] | "Step 3: Plugging it all into production..." |
| **9:30 - 10:00** | [Card overlay pointing to related video. Host points to screen corner.] | "Now that your backend handles this load, your database is the next bottleneck. Watch this video next to fix your query indexing." |

## Template 2: 45-Second Short-Form Video Script

Designed for vertical 9:16 format (YouTube Shorts, Instagram Reels, TikTok).

```text
[0:00 - 0:03] THE HOOK
Visual: Host holds up phone/device or points to screen showing dramatic before/after.
Text On Screen: "Stop doing [Common Habit] in [Tool]"
Verbal: "If you're still doing [Habit] in [Tool], you are wasting at least 2 hours every week."

[0:03 - 0:10] THE REFRAME
Visual: Fast jump cut to screen recording. Yellow highlight box around the problem.
Verbal: "Most people think they need [Complex Tool], but you can do it natively with this shortcut."

[0:10 - 0:35] THE STEP-BY-STEP PAYOFF
Visual: Quick zoom on the keyboard shortcut, then immediate result on screen. SFX: Pop sound effect.
Verbal: "First, press [Shortcut]. Next, toggle this setting from False to True. Watch what happens when I save."

[0:35 - 0:45] THE TAKEAWAY / SEAMLESS LOOP
Visual: Cut back to host smiling.
Verbal: "Save this video for your next project, and hit follow for more [Niche] breakdowns."
```
