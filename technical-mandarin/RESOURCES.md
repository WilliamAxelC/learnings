# Technical Mandarin for AIOps Engineering Resources

## Knowledge

- [Huawei Cloud AOM (Application Operations Management) Official Documentation — 华为云应用运维管理文档](https://support.huaweicloud.com/aom/index.html)
  Primary source for authentic Huawei terminology across observability (`可观测性`), alert noise reduction (`告警降噪`), metric monitoring (`指标监控`), log analysis (`日志分析`), and root cause analysis (`根因分析`). Use for: verifying exact Huawei product and internal engineering nomenclature.
- [AllSet Learning Chinese Grammar Wiki — B1/B2 Grammar Points (HSK 3–4)](https://resources.allsetlearning.com/chinese/grammar/)
  High-trust, structured reference for reactivating HSK 3 sentence patterns and upgrading to formal workplace connectors (`由于`, `导致`, `通过`, `针对`, `目前`). Use for: grammatical structure checks and cause-and-effect sentence skeletons.
- [Google SRE Book (Chinese Edition) — _Google 运维解密 / 站点可靠性工程_](https://sre.google/books/)
  Industry-standard reference for incident response (`故障响应`), postmortems (`事后复盘`), SLAs/SLOs (`服务等级目标`), MTTR (`平均修复时间`), and alert fatigue (`告警疲劳`). Use for: standard Chinese SRE & DevOps phrasing.
- [MDBG Chinese-English Dictionary](https://www.mdbg.net/chinese/dictionary)
  Fast lookup for Pinyin tone marks, character decomposition, and compound word usage. Use for: tone verification and breaking 4-character technical compounds into memorable 2-character roots.

## Wisdom (Communities)

- [Huawei Cloud Developer Community — AIOps & Cloud Native (华为云开发者社区)](https://bbs.huaweicloud.com/)
  Active engineering forum where Huawei engineers publish architecture deep-dives, AIOps case studies, and troubleshooting guides. Use for: observing how Huawei tech leads and architects naturally frame technical problems.
- [InfoQ China — Operations & Observability Track (InfoQ 极客邦运维与可观测性专栏)](https://www.infoq.cn/topic/operations)
  Production postmortems, LLM-ops articles, and conference talks from senior engineers at Huawei, Alibaba, and Tencent. Use for: listening to real technical talks and picking up spoken transitional phrases used by engineering leaders.
- [V2EX — DevOps & Programmer Nodes (`v2ex.com/go/devops`)](https://www.v2ex.com/go/devops)
  High-signal Chinese developer forum discussing real-world production incidents, monitoring pipelines, and engineering team dynamics. Use for: colloquial workplace shorthand (`背锅`, `上线`, `压测`, `排查`, `复盘`).

## Gaps

- Standard Mandarin textbooks teach HSK 3–4 using everyday life scenarios rather than software engineering or AIOps workflows. We bridge this gap in `./reference/` and `./lessons/` by mapping dormant HSK 3 grammar directly onto Huawei AIOps incident briefings, RCA reviews, and 1-on-1 status updates.
