## Structure Convention

Each topic track follows a consistent layout:
- `README.md`: Syllabus, module overview, and progress tracking.
- `0X-module-name/guide.md`: Core mental models, frameworks, and practical guidelines.
- `0X-module-name/exercises.md`: Hands-on drills with actionable output templates.
- Optional checklists and templates for workflows.
