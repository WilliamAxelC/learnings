# Pablo Stanley Vector Asset Library for Video Generation

A production-ready, fully-cataloged library of **335 hand-drawn vector (SVG) assets** created by **Pablo Stanley** (Open Peeps, Open Doodles, Humaaans, Cityscapes, Happy Bunch). Curated and structured specifically for automated AI video pipelines, motion graphics, Remotion, Motion Canvas, and YouTube/Shorts content creation.

All assets adhere strictly to Pablo Stanley's cohesive black-ink vector illustration aesthetic (3px–4px stroke weight, clean silhouettes, expressive doodles) and are released under **CC0 / MIT** licenses for free commercial and personal use.

## Machine-Readable Catalog (`catalog.json`)

All 335 assets are indexed in `catalog.json` with categories, semantic tags, moods, and dimensions. AI agents can query this JSON to automatically select matching visuals for video beats.

### Schema Example:
```json
{
  "id": "scenes-cityscapes-big-apple",
  "name": "Big Apple Skyline",
  "category": "scene",
  "subcategory": "cityscape",
  "file": "big-apple.svg",
  "path": "scenes/cityscapes/big-apple.svg",
  "tags": ["scene", "cityscape", "big", "apple", "background", "environment", "urban", "skyline", "metropolis"],
  "mood": "neutral",
  "style": "pablo-stanley-vector",
  "viewBox": "0 0 3871 2367"
}
```

### Agent Query Helper Example:
```javascript
const catalog = require('./catalog.json');

// Find a stressed character or prop
const stressedAssets = catalog.assets.filter(a => a.mood === 'stressed');

// Find all coffee and cafe assets
const cafeAssets = catalog.assets.filter(a => a.tags.includes('coffee') || a.tags.includes('cafe'));
```

## Dynamic Character Assembler (`assemble-peep.js`)

A zero-dependency Node.js CLI and module that dynamically stitches any combination of modular Open Peep parts into a single crisp SVG.

### CLI Usage:
```bash
# Generate a smiling cafe barista
node assemble-peep.js --hair bun-curly --face smile --body button-shirt --out my-barista.svg

# Generate a driven founder with goatee
node assemble-peep.js --hair afro --face driven --body hoodie --facial-hair goatee --out founder.svg

# Generate a skeptical reviewer with glasses
node assemble-peep.js --hair bald-sides --face suspicious --body turtleneck --accessory glass-round-thick --out critic.svg

# List all available modular parts
node assemble-peep.js --list
```

### Programmatic Usage in Video Pipelines:
```javascript
const { assemblePeep } = require('./assemble-peep');

const customSvg = assemblePeep({
  hair: 'short-messy',
  face: 'driven',
  facialHair: 'goatee',
  accessory: 'sunglass-wayfarer',
  body: 'blazer',
  strokeColor: '#111827',
  backgroundColor: '#FDE047'
});

fs.writeFileSync('character.svg', customSvg);
```

## Remotion Integration Recipe

```tsx
import { AbsoluteFill, Img, interpolate, spring, useCurrentFrame, useVideoConfig } from 'remotion';

export const NarrativeScene = () => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();

  // Gentle floating bounce
  const bounce = Math.sin(frame / 12) * 8;
  
  // Spring pop-in for character
  const scale = spring({ frame, fps, config: { damping: 12, stiffness: 120 } });

  return (
    <AbsoluteFill style={{ backgroundColor: '#F8F9FA' }}>
      {/* Background Cityscape */}
      <Img
        src={require('./assets/scenes/cityscapes/downtown.svg')}
        style={{ position: 'absolute', bottom: 0, width: '100%', opacity: 0.25 }}
      />

      {/* Interior Desk */}
      <Img
        src={require('./assets/scenes/interiors/modern-desk.svg')}
        style={{ position: 'absolute', bottom: 50, left: 100, width: 600 }}
      />

      {/* Animated Character */}
      <Img
        src={require('./assets/characters/presets/barista-smiling.svg')}
        style={{
          position: 'absolute',
          bottom: 120,
          right: 180,
          width: 500,
          transform: `scale(${scale}) translateY(${bounce}px)`
        }}
      />
    </AbsoluteFill>
  );
};
```
